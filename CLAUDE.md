# Project instructions

This is "Tend", a dental routine planner in the product discovery and visual design phase. Start every session by reading `HANDOFF.md`, which holds all decisions, preferences, palette status and open questions.

Rules for this project:
- Do not build the full application. Phase 1 is discovery and design mockups only, unless the user says otherwise.
- All clinical content is illustrative and unreviewed. Never present it as medical or dental advice, and keep safety wording ("ask your dentist") intact.
- Recommendations come from deterministic, reviewed rules, not from an AI model.
- Take colour and layout inspiration from other apps if asked, but never copy another company's logo, illustrations, wordmark or name.
- Ask before publishing pages, deleting files or pushing anything outside this machine.
- Prefer showing visual mockups over long text. Keep replies short and plain.
- The files in `artboard/project/` are Design canvas sources and need the canvas runtime to render. Edit them with care and keep `canvas.json` consistent with the files.
